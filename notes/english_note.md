### Important special cases

These **do not change** between singular and plural:

| Singular   | Plural     |
| ---------- | ---------- |
| **had**    | **had**    |
| **did**    | **did**    |
| **could**  | **could**  |
| **would**  | **would**  |
| **should** | **should** |
| **might**  | **might**  |
| **must**   | **must**   |
| **can**    | **can**    |
| **will**   | **will**   |
| **may**    | **may**    |

### The main pattern to memorize

For **present simple normal verbs**:

**Singular:** `verb + s/es`
**Plural:** `base verb`

Examples:

* works → work
* goes → go
* needs → need
* studies → study
* watches → watch
* tries → try

But the three big irregular ones are:

**is → are**
**has → have**
**does → do**

And in the past:

**was → were**
**had → had**
**did → did**

That's the core Subject–Verb Agreement list you need.
